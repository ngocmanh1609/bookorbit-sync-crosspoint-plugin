**cp-orbit 0.2.0**, BookOrbit for CrossPoint.

> **Verified on the BOOX Picco (CrossPoint 2.0.0) only.** Other CrossPoint readers may work but are untested.

## What's new

- **Collections and SmartScopes in the reader's catalog.** Home → Plugins → BookOrbit now lists your libraries, then
  each collection (`Collection · …`) and SmartScope (`SmartScope · …`). Empty ones are hidden.
- **They follow your server automatically.** The web card updates the lists every time its page opens and after
  Save. The **Update shelves** button is gone.
- **Fixed:** the web card's Server field was narrower than the other fields and cut the address off.

CrossPoint's plugin catalog has one level of lists, so collections and SmartScopes are listed directly rather than
inside folders. See the README for details.

## Update

1. Use **Sync progress** on the reader.
2. Copy the new `cp-orbit` folder over the old one, then turn the reader off and on.
3. Open the reader's **Plugins** web page once, so your collections and SmartScopes are added.

Settings are kept in `/.cp-orbit/`.
